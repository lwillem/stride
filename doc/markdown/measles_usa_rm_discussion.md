## B. Modelling decisions — the merge cannot proceed without these

### B1. Workplaces of size 1

Both sides wrote the same removal independently; it is **live on theirs, commented out on ours**.

```r
# Remove workplaces with 1 person
workplace_id_freq    <- table(pop_usa$workplace_id)
small_workplace_id   <- names(workplace_id_freq[workplace_id_freq <= 1])
pop_usa$workplace_id <- ifelse(pop_usa$workplace_id %in% small_workplace_id, NA, pop_usa$workplace_id)
```

`measles_usa` has it commented out at `social_contacts_usa2026.R:171-174`; theirs runs it.

The question is not stylistic. A one-person workplace contributes zero workplace contacts
but still counts as employment in `age_distr_workplace`, which is the denominator of the
conditional contact rate. Removing them raises the conditional rate for everyone else.
It also interacts with **B2** and **B3**.

### B3. Cluster-size adjustment factors — present on ours, absent on theirs

The largest functional divergence in the contact pipeline. `measles_usa` (commits
`14282ce`, `63ec556`, `87fe899`) estimates school and workplace adjustment factors by
`uniroot`, so that larger venues compensate for smaller ones that cannot reach the target
contact rate, and writes them into the contact-matrix XML:

```xml
<adjustment_factor>
  <workplace><value>…</value></workplace>
  <school><value>…</value></school>
</adjustment_factor>
```

`AgeContactProfile.cpp:53` reads that node and scales the whole age profile.
`origin/measles_usa_rm` has **none of this** — neither the estimation nor the XML node.
In its place is an exploratory calculation only (`num_people_workplace_leq7`).

Consequences to discuss:

- A contact matrix generated by their script and one generated by ours are **not
  interchangeable**; the same population will give different contact rates.
- Which matrices were the runs on each side actually done with?
- The unresolved issue in `87fe899` — the school factor's **age-specific behaviour** —
  is still open. Likely cause (plan F9): `adj_fctr_school` is a single scalar applied to
  all ages, while the target is an unweighted mean over enrolled ages and the school-size
  distribution is pooled across all ages; primary and secondary schools differ
  substantially in size. **Worth solving together.**

> **Decision — adopt the adjustment factors as standard? and how to handle the age-specific school issue:**
> ______________include in the measles_usa_rm branch. not-age specific is OK for now________________________________
